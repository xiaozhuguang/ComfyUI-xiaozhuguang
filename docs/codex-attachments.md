# 添加原图和原视频到 Codex

重启 ComfyUI 并刷新页面后：

- 图像加载器·化神级：选中图片，鼠标移入预览区，点击「添加到 Codex」悬浮按钮。多选时添加选中的原图。
- 视频加载·化神级：鼠标移入预览区，点击「添加到 Codex」，添加当前选中的完整原视频。

图像加载器侧栏的「清空」下方有分割线和「设置」，可关闭 Codex 悬浮按钮。视频加载器预览区的「设置」可分别关闭其他悬浮按钮，设置按钮本身不提供关闭选项。面板点击「保存」才应用，点击「取消」不改变配置；配置保存在当前节点的工作流属性中，保存并重新打开工作流后恢复，不影响其他工作流。

助手将 input 中已有的原文件复制到 Windows 文件剪贴板（也兼容带类型标记的 output/temp 文件），激活 Codex，聚焦聊天输入框并按 Ctrl+V。不调用附件菜单或文件选择窗口。不会另存、转码、抽帧，不包含加载器中的裁剪、蒙版或视频截取设置，也不自动发送聊天消息。粘贴后请检查附件预览，再输入问题发送。

操作开始时记录原来的前台窗口，粘贴按键发出约 250 毫秒后切回原窗口，方便继续在 ComfyUI 选择图片或视频。中途若手动切到了其他应用，助手不会再抢回焦点。自动粘贴失败时也会尝试返回原窗口。

使用条件：ComfyUI 和 Codex 运行在同一台 Windows 电脑，通过 localhost 或 127.0.0.1 打开 ComfyUI。需要 Windows PowerShell 和允许执行本地脚本的系统策略。自动粘贴要求 Codex 已打开目标聊天、只有一个主窗口，且聊天输入框可通过辅助功能聚焦。

复制会替换剪贴板内容。无法自动聚焦或粘贴时，原文件仍在剪贴板中，可在目标聊天输入框手动按 Ctrl+V。只复制文件列表，不复制路径文字，也不移动或删除源文件。按键发送成功不代表目标应用已接收附件；实际附件粘贴仍需在当前 Codex 版本验证。

切换提速：后端在启动 PowerShell 前先校验并激活唯一的 Codex/ChatGPT 主窗口；输入框已聚焦且名称或控件标识匹配时直接粘贴，否则仍按原规则定位。每轮定位只遍历一次编辑控件，Windows 桥接程序集使用缓存。需要重启 ComfyUI 以加载后端优化。
