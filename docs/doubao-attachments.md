# 添加到豆包

重启 ComfyUI 并刷新页面后，在以下节点的预览区点击「添加到豆包」：

- 小珠光图片加载器：添加选中的原图；未多选时添加当前图片。
- 小珠光视频加载器-化神级：添加当前完整原视频。
- 小珠光视频保存-化神级：添加最近一次生成的视频，支持已登记文件令牌的自定义输出目录。

按钮可在对应节点的设置中隐藏，设置随工作流保存。原有「添加到 Codex」继续保留。

通过 localhost 或 127.0.0.1 访问 ComfyUI，且豆包电脑版运行在同一台 Windows 电脑。助手复制原文件到文件剪贴板，尝试定位唯一的豆包主窗口和聊天输入框并粘贴，随后返回原窗口；不会点击发送。复制会替换剪贴板内容，不转码或抽帧，不应用加载器里的裁剪、蒙版和截取设置。

请先切换到豆包工作模式，打开目标聊天并点击聊天输入框。助手激活唯一的豆包主窗口后直接向当前焦点发送 Ctrl+V，不再等待输入框遍历；已识别出的搜索框、密码框或前台窗口切换会中止粘贴。ComfyUI 后端会在启动 PowerShell 前先激活经过进程校验的唯一豆包窗口，减少切换前的等待；原窗口会传给桥接助手用于粘贴后恢复。Windows 桥接程序集按源码版本缓存，首次编译后后续点击直接加载。

自动粘贴失败时，在豆包工作模式的目标聊天输入框手动按 Ctrl+V。自动定位仅支持电脑版。提示已尝试粘贴不代表豆包已接收附件，请检查附件预览。文件大小、格式限制取决于豆包当前版本和聊天能力。

自定义输出目录的文件令牌在 ComfyUI 重启后失效，需要重新执行保存节点。此功能只传递附件，不包含豆包回复或生成素材自动回传，也不需要 API Key。
