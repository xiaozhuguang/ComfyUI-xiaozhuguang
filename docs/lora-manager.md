# 小珠光 LoRA 管理加载器

重启 ComfyUI 并刷新浏览器后，在侧栏「小珠光 LoRA」打开管理器，或添加「小珠光 LoRA 管理加载器」节点并点击「打开 LoRA 管理器」。

管理器默认全屏显示，不提供窗口拖动和缩放。卡片尺寸统一，名称和路径单行省略；鼠标移入卡片时立即显示完整文件名。

- 自动扫描 ComfyUI 已配置的 LoRA 根目录。卡片显示文件名，不显示路径；点击「打开目录」在本机 Windows 文件管理器中打开模型所在文件夹。
- 名称直接使用模型文件名，不提供自定义显示名称。点击卡片编辑标签、备注、触发词和推荐强度；点击「保存资料」写入磁盘。
- 上传缩略图后立即保存；按标签、收藏、关键字筛选。
- 搜索支持空格分隔多个词，不区分英文大小写，顺序不限；每个词可分别匹配文件名、标签、备注或触发词。
- 「清理全部维护资料」会弹出警告，等待 5 秒后再次点击确认才执行；取消不清理。清理备注、标签、触发词、收藏、推荐强度与缩略图，保留 LoRA 模型文件、记录 ID 和节点加载列表。
- 点击「添加 LoRA」加入加载节点。节点按钮可切换「串联（多选）」和「并联（单选）」：串联时多个启用项按列表顺序叠加；并联时勾选某项会自动停用其他项，每次只加载一个。模式与已添加状态随节点和工作流保存。支持一键清空当前加载列表、单条启停、强度调整和拖动排序。节点仅输入、输出 MODEL，不应用 LoRA 的文本编码器权重；旧工作流的 CLIP 连线会移除，需要直接连接原文本编码器。
- 左侧显示真实文件夹；右键子文件夹，从菜单选择「重命名文件夹」。拖拽卡片到文件夹移动文件。不提供新建文件夹功能。目前仅支持同一根目录内移动，遇到重名拒绝覆盖；批量操作已完成的文件不会因后续冲突自动回退。
- 通过管理器移动文件会保留资料 ID，自己的加载节点能找到新位置。其他加载节点保存的旧路径需要手动修正。
- 打开管理器或刷新列表时自动清理找不到文件的记录，同时删除对应备注、标签与缩略图。外部移动或重命名也会按原文件缺失处理；通过管理器内部移动或重命名目录可保留关联资料。

资料固定保存在 `ComfyUI/user/xiaozhuguang/lora_manager/library.json`，缩略图在同级 `thumbnails/`。不提供自定义资料目录，不进行自动备份。

画布上方工具栏的小珠光 Logo 设置提供统一「导入导出配置」入口，勾选「LoRA 管理资料（含缩略图）」即可打包到统一 ZIP。包内包含整理资料和缩略图，不包含 LoRA 权重。导入时合并记录，同路径记录使用导入资料覆盖，未勾选时不修改 LoRA 资料。请先确保本地模型路径与备份一致；扫描时找不到的记录会被自动清理。LoRA 管理面板不单独提供导入导出入口。

加载能力使用 ComfyUI 原生 LoRA 接口，兼容范围取决于当前 ComfyUI 及输入模型。
