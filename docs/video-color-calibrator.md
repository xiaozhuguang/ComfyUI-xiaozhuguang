# 小珠光视频颜色矫正

输入为帧数相同、时间和空间位置对齐的原版与编辑版视频。固定使用稳健分位数匹配，无模式下拉框。节点名称和图像接口保留；前端加载旧工作流时自动移除旧模式值，保留时间平滑和强度。旧 API 的 mode 参数仍接受，但统一使用分位数算法。

- **亮度与对比度**：使用编辑版亮度的加权分位数划分邻域，在每个邻域内用同一位置的原版/编辑版像素稳健估计亮度差，避免两张图独立排序导致灯光与人物被错配。适用于 gamma、暗部及高光变化。分位点使用 1%—99% 范围，从中间调向两侧约束斜率；观测范围之外保持端点亮度差，不沿噪声斜率继续扩展。
- **内容差异**：在最长边 128 像素的缩略图上，先评估全像素颜色拟合是否可靠；当明显存在内容替换且仍有足够相似区域时，以相似区域初始化并持续保留该权重先验，防止后续拟合重新被替换人物主导。正常全局曝光/对比度变化仍使用完整亮度范围。随后以带恒等正则的 RGB 仿射拟合和迭代残差筛选估计稳定区域。变更区域不参与或少参与参数估计，但输出仍使用全帧统一变换。
- **色相、饱和度、偏色**：在 R−Y、B−Y 色度平面拟合统一的二维矩阵与偏移，允许色相旋转及饱和度变化，并限制增益，避免 HSV 统计与 RGB 色度调整定义不一致。色度重建保持估计亮度，禁止色度平面反射，并在增益限幅后重新计算偏移，最后统一裁剪色域。
- **视频稳定性**：所有校正参数做 EMA 平滑；仅当两路输入相邻缩略图的平均绝对差都超过 0.18 时重置历史，避免编辑版单帧跳变清空历史。该切镜检测为启发式，快速运动和双路闪光也可能触发。匹配不可靠时原样输出该帧，并在失配帧及恢复帧处切断历史，不从邻帧插值或沿用校正。对邻帧一致、单帧突变且实际拟合误差偏大的参数进行抑制；拟合良好的真实变化仍参与正常平滑。平滑设为 0 时逐帧独立，不进行这些时间修复。
- **强度**：完成全部校正与色域裁剪后再混合；0 严格透传。无随机抖动和混合后的强制均值锚定。
- **统计不足**：有效对应像素不足64，或最终有效像素未覆盖至少12个8×8网格区域（各区域有效覆盖至少25%）且跨至少两个象限时，原样输出并切断历史，不回退到全帧强制匹配。稳定像素比例低于 30% 时降低校正幅度。
- **输入与资源**：验证帧数、形状及非有限值，保留编辑版 alpha、设备和数据类型；逐帧处理，不自动将整段视频搬到 GPU。原版尺寸不同时先缩放对齐。

## 使用与限制

固定使用分位数匹配，时间平滑默认 0.6，兼顾整体曝光、对比度及非线性明暗变化。提高平滑会降低闪动，但响应变慢。

算法没有光流、物体识别或语义遮罩。明显错位、主体整体重绘、大多数区域替换，以及已丢失的高光/暗部细节，不能保证恢复。全局颜色与内容变化无法在所有情况下唯一分离；缩略图也可能忽略很小的变化区域。局部照明差异无法由单个全局变换完全校正。

## 2026-11-05 防止相近画面被校正发灰

复现：相同颜色分布的暖色画面，仅平移一像素，条件均值亮度拟合仍可能因对应关系偏差而将对比度压低约19%。相同输入与简单曝光变化本身不触发此问题；时间平滑不能修复整段偏差。

新增亮度曲线校验：以5%—95%的亮度跨度检查所选像素对完整画面的覆盖。完整画面跨度大于0.04且样本跨度不足其一半时，只应用稳健亮度偏移，不估计整帧对比度。分别检查5%—95%及25%—75%跨度，拟合曲线不得将其压到原版/编辑版对应跨度较小值的95%以下；不满足时同样退为亮度偏移。参考画面确有充分支持的低对比度仍允许匹配，不强制增艳或增对比度。

该复现用例中，对比度比值从约0.806恢复到约1.0；新增空间偏移、暗部样本覆盖不足、真实对比度降低三个回归测试。对用户本次异常成片的检查确认对比度下降，但没有该次校正前的生成张量，不能把合成用例验证视作原工作流最终合成验收。

## 超级近景与构图变化时自动跳过

自动检查空间对应关系。颜色拟合前，先在最长边128像素缩略图上检查空间对应关系：8×8区域分别计算局部亮度相关性和高频结构相关性，抑制仅有相似肤色但眉眼、脸部构图不对应的误匹配。至少12个区域通过检查，且分布跨越至少两个象限，才用这些区域参与颜色拟合。可由完整画面可靠解释的正常全局颜色变换，以及结构一致的平滑非线性亮度变化，保留完整亮度范围；纯色图像仍允许估计常量偏移。

整段缺少可靠对应区域时，自动原样输出编辑版，保留其亮度、对比度、颜色和alpha。任何不可靠匹配均直接透传，并在恢复时重新估计，不沿用失配前历史。检测依赖结构启发式，不包含人脸识别或光流，不保证识别所有不可靠匹配；也不会无条件跳过所有近景。

2026-11-08 用用户提供的 `V1-0033_镜头__6177.mp4` 与 `一采V1-0033_镜头__6177_5.mp4` 解码至128×72检查：两段均为66帧，全部帧未通过结构检查，节点输出逐像素保留所提供的编辑版。旧颜色筛选在第22、44、66帧分别接受约44%、61%、61%的像素，说明肤色相近可造成错误的颜色置信度。所提供编辑版已经校正过，该检查验证自动拒绝，不能证明恢复了校正前生成结果；应在原工作流重新执行以保留未校正的生成视频。

取消「启用颜色匹配」开关，只保留「时间平滑」「校正强度」控件。若后面另接ATR，其「边缘颜色匹配」仍独立生效。更新后需重启ComfyUI后端并刷新页面。


## 2026-11-08 降低误匹配风险

发现并修复：结构检查拒绝的帧仍可能经时间平滑获得旧校正或邻帧插值。现在所有可靠性检查失败都立即原样输出，并切断前后历史。结构通过区域先筛选，再进行稳健颜色拟合，避免已拒绝的内容主导初始估计；最终有效像素还必须具备足够的空间分布。拟合结果在可信像素上的误差若比不校正更大（容差0.001）或出现非有限值，同样拒绝。

这是保守取舍：难匹配片段可能减少校正，失配边界也可能出现校正幅度变化。可靠像素上误差改善不能证明整帧语义匹配正确；重复纹理、同构但不同内容、纯色画面及未观测颜色仍有歧义。无法给出真实误判概率或保证零风险。验证为直接执行节点的合成回归，未将其视为用户原视频最终视觉验收。
