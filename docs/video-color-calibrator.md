# 小珠光视频颜色矫正

输入为帧数相同、时间和空间位置对齐的原版与编辑版视频。固定使用稳健分位数匹配，无模式下拉框。节点名称和图像接口保留；前端加载旧工作流时自动移除旧模式值，保留时间平滑和强度。旧 API 的 mode 参数仍接受，但统一使用分位数算法。

- **亮度与对比度**：使用编辑版亮度的加权分位数划分邻域，在每个邻域内用同一位置的原版/编辑版像素稳健估计亮度差，避免两张图独立排序导致灯光与人物被错配。适用于 gamma、暗部及高光变化。分位点使用 1%—99% 范围，从中间调向两侧约束斜率；观测范围之外保持端点亮度差，不沿噪声斜率继续扩展。
- **内容差异**：在最长边 128 像素的缩略图上，先评估全像素颜色拟合是否可靠；当明显存在内容替换且仍有足够相似区域时，以相似区域初始化并持续保留该权重先验，防止后续拟合重新被替换人物主导。正常全局曝光/对比度变化仍使用完整亮度范围。随后以带恒等正则的 RGB 仿射拟合和迭代残差筛选估计稳定区域。变更区域不参与或少参与参数估计，但输出仍使用全帧统一变换。
- **色相、饱和度、偏色**：在 R−Y、B−Y 色度平面拟合统一的二维矩阵与偏移，允许色相旋转及饱和度变化，并限制增益，避免 HSV 统计与 RGB 色度调整定义不一致。色度重建保持估计亮度，禁止色度平面反射，并在增益限幅后重新计算偏移，最后统一裁剪色域。
- **视频稳定性**：所有校正参数做 EMA 平滑；仅当两路输入相邻缩略图的平均绝对差都超过 0.18 时重置历史，避免编辑版单帧跳变清空历史。该切镜检测为启发式，快速运动和双路闪光也可能触发。非零平滑时，同一镜头内最多六帧短暂失配可用相邻可靠参数插值；无可靠右邻时短暂沿用历史，持续失配则逐步减弱校正。对邻帧一致、单帧突变且实际拟合误差偏大的参数进行抑制；拟合良好的真实变化仍参与正常平滑。平滑设为 0 时逐帧独立，不进行这些时间修复。
- **强度**：完成全部校正与色域裁剪后再混合；0 严格透传。无随机抖动和混合后的强制均值锚定。
- **统计不足**：有效对应像素不足 64 或不足 5%、或整体对应关系不足时，不采纳本帧估计；无历史可用时透传，有历史时按上述时间修复规则处理，不回退到全帧强制匹配。稳定像素比例低于 30% 时降低校正幅度。
- **输入与资源**：验证帧数、形状及非有限值，保留编辑版 alpha、设备和数据类型；逐帧处理，不自动将整段视频搬到 GPU。原版尺寸不同时先缩放对齐。

## 使用与限制

固定使用分位数匹配，时间平滑默认 0.6，兼顾整体曝光、对比度及非线性明暗变化。提高平滑会降低闪动，但响应变慢。

算法没有光流、物体识别或语义遮罩。明显错位、主体整体重绘、大多数区域替换，以及已丢失的高光/暗部细节，不能保证恢复。全局颜色与内容变化无法在所有情况下唯一分离；缩略图也可能忽略很小的变化区域。局部照明差异无法由单个全局变换完全校正。

## 2026-11-05 防止相近画面被校正发灰

复现：相同颜色分布的暖色画面，仅平移一像素，条件均值亮度拟合仍可能因对应关系偏差而将对比度压低约19%。相同输入与简单曝光变化本身不触发此问题；时间平滑不能修复整段偏差。

新增亮度曲线校验：以5%—95%的亮度跨度检查所选像素对完整画面的覆盖。完整画面跨度大于0.04且样本跨度不足其一半时，只应用稳健亮度偏移，不估计整帧对比度。分别检查5%—95%及25%—75%跨度，拟合曲线不得将其压到原版/编辑版对应跨度较小值的95%以下；不满足时同样退为亮度偏移。参考画面确有充分支持的低对比度仍允许匹配，不强制增艳或增对比度。

该复现用例中，对比度比值从约0.806恢复到约1.0；新增空间偏移、暗部样本覆盖不足、真实对比度降低三个回归测试。对用户本次异常成片的检查确认对比度下降，但没有该次校正前的生成张量，不能把合成用例验证视作原工作流最终合成验收。
