# 复制原文件到剪贴板

重启 ComfyUI 并刷新页面后，以下化神级节点统一使用「复制到剪贴板」按钮，替代「添加到 Codex」与「添加到豆包」：

- 图片加载器：复制选中的原图文件；没有多选时复制当前图片。
- 视频加载器：复制当前选择的完整原视频。
- 视频保存：复制最近一次保存的视频，支持已登记文件令牌的自定义输出目录。

复制后在 Codex、豆包或其他支持文件粘贴的应用中按 Ctrl+V。功能只写入 Windows 文件剪贴板，不定位聊天窗口、不切换焦点、不模拟粘贴，也不自动发送。成功提示显示 2 秒。无需运行 Codex 或豆包。

请通过 localhost 或 127.0.0.1 访问本机 ComfyUI。复制会替换当前剪贴板内容，不转码、不抽帧，也不应用加载器里的裁剪、蒙版和截取设置。

按钮可在节点设置中显示或隐藏，旧工作流中的 Codex/豆包按钮设置会合并为剪贴板按钮设置。自定义输出目录的文件令牌在重启 ComfyUI 后失效，需要重新执行保存节点。
