# ATR 接缝颜色匹配

开启「边缘颜色匹配」后，只在自动羽化过渡区修正亮度增益、亮度偏移和色度偏移；主体内部完全保留区域不参与输出修正。接口与参数顺序保持不变。

- 接缝带使用同位置像素做稳健拟合。有明显内容替换且仍有相似背景时，持续保留背景权重先验，避免初始模型和后续迭代被替换区域带偏。正常全局亮度与对比度变化继续使用完整取样范围。
- 使用最终筛选权重重新拟合参数；限制亮度增益、偏移和色度偏移，低置信度时降低幅度。
- 时间平滑大于 0 时，短暂失配最多沿用六帧历史，之后每帧向无校正状态减弱 25%，不突然清空校正。初始帧无可靠历史时不修正。
- 历史重置基于两路完整裁剪画面的低分辨率结构变化，不依据取样带平均明暗。该检测为启发式，不能保证识别所有切镜。
- 时间平滑为 0 时逐帧独立，不沿用历史。历史仅在本次批次内生效，CPU逐帧和GPU分块采用相同因果规则，不跨执行保存参数。

重启 ComfyUI 后端后加载实现。关闭边缘颜色匹配或匹配强度为 0 时不进入该路径。

验证：`python -m unittest discover -s tests -p test_atr_edge_color.py -v`。
覆盖六帧失配、长失配渐退、平滑关闭、亮度变化与结构切镜、内容替换、正常亮度/对比度、作用范围、CPU与分块计算一致性、NumPy适配及公开回贴接口。分块测试在CPU张量上执行，不能替代CUDA硬件验收。

另外检查发现 `test_atbc_seam_context.py` 的两项旧几何测试与当前自动接缝行为不一致；验证其失败过程中颜色匹配函数调用为0次，不属于此次颜色路径修改。自动接缝与补边测试单独检查。
