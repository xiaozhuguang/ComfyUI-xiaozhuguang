# ATBC · 高级：视频稳定跟踪

`auto` 使用遮罩包围框的实际宽高比估算目标尺寸，不再吸附到五个预设比例。
普通裁剪先取整批裁剪框宽度、高度的中位数确定参考比例，统一选择一次输出尺寸；
每张图的源裁剪框分别扩充以适配该尺寸，不再逐张选尺寸后补边到最大宽高。
遮罩求和按合并后的遮罩计算；视频稳定跟踪使用
有效帧包围框的宽度中位数 / 高度中位数，确定全片统一比例。
先按目标千像素与裁剪比例估算理想宽高，再组合宽、高各自上下相邻的32倍数，
优先选择总像素最接近目标的组合；像素误差相同时选择最接近裁剪比例的组合。
如“整除数”另有要求，使用它与32的最小公倍数作为尺寸步长。
例如1000千像素、裁剪比例2.5时选择1568×640，共1003520像素。
扩充模式按所选输出比例扩大源裁剪框，完整覆盖原遮罩及扩展范围，再等比缩放。
手动比例预设、关闭裁剪和未接遮罩的路径沿用原有尺寸规则。
已有工作流使用 `auto` 时，裁剪范围与输出分辨率可能随此变更而改变。

裁剪框超出原图时，有效图像区域与填充区域分别缩放，并在CROPBOX中记录
`source_valid_box`、`output_valid_box`。ATR按这些坐标单独还原有效区域，
避免白色补边经过插值混入原图边缘。CPU与GPU回贴均支持；旧CROPBOX沿用旧路径。
该修正需要重新执行ATBC生成新裁剪信息，不能清除旧裁剪结果中已经混入的白边。

ATBC另外记录原图坐标下的 `seam_box`：使用相同比例、扩展倍数1、像素扩展0
计算的裁剪框，并限制在原图范围内。它不包含稳定余量、平滑补偿或整除对齐增加的范围。
ATR未接遮罩时，使用此框作为融合范围，再应用遮罩扩张和羽化；增加处理上下文
不再直接把接缝推到扩展后的裁剪框边缘。接了遮罩时仍以显式遮罩为准。
贴着原图边界的一侧不额外生成接缝。旧裁剪信息没有此字段时保留原处理方式。
羽化外沿或正向遮罩扩张仍受实际提供的处理上下文限制，需留足相应余量。

ATBC · 高级界面统一使用人脸构图。旧界面工作流自动迁移，以下裁剪模式说明适用于旧版和兼容 API。

- 裁剪模式：逐帧裁剪 / 视频稳定跟踪 / 人脸构图。
- 跟踪偏好：稳定优先 / 紧凑优先，仅稳定跟踪生效。
- 缩放方式：固定大小 / 动态缩放，仅稳定跟踪生效。

关闭裁剪或未接遮罩时，仍使用整图目标千像素缩放与四周补边。
遮罩求和优先于跟踪：全片共用一个固定裁剪框。
逐帧裁剪使用每帧遮罩单独确定裁剪框。裁剪按对齐后的输出宽高比等比缩放，优先使用原图内可完整覆盖遮罩的范围。原图无法容纳该比例的遮罩时，用填充颜色补足。

稳定跟踪先按扩展倍数、像素扩展和比例计算每帧必须覆盖的范围，
再规划整段裁剪框。「位置平滑」控制视频稳定跟踪和人脸构图的中心轨迹。
固定模式使用相同宽高，动态模式使用「缩放平滑」控制大小的前瞻包络和平滑，
始终覆盖必须保留的范围。稳定优先额外增加15%空间，以减少移动。
位置采用稀疏线性规划，在覆盖约束内最小化总移动距离，并轻微偏向主体中心。
这是一套独立实现，不复制或依赖MVEx插件；运动轨迹不保证与MVEx相同。

短暂空遮罩帧使用前后有效框插值，首尾缺失沿用最近的有效框。
整段遮罩为空时使用整图。单遮罩支持广播，多遮罩数量必须与图片数量一致。

稳定跟踪路径保留浮点图像，以CPU浮点Lanczos4缩放；遮罩使用线性缩放。
只上传遮罩范围所需的CPU数据，不为裁剪加载GPU模型，也不新增GPU常驻缓存。
输出统一分辨率，整除对齐使用居中填充，奇数余量在右侧/下侧多补1像素。
逐帧裁剪路径仍保留其原有8位处理行为，避免本次升级改变已有工作流效果。

输出继续是IMAGE / CROPBOX / MASK。每帧记录原图坐标、原图补边、输出内容区域、
输出尺寸和裁剪源尺寸。ATR · 高级先移除输出补边，再按对应帧的原裁剪尺寸回贴。
动态缩放时请保持处理结果的帧顺序与数量，避免时间重排后坐标不再对应。

验证覆盖：扩展范围、固定/动态尺寸、位置稳定、单遮罩广播、空遮罩、
比例与整除、居中补边、CPU回贴，以及GPU回贴的遮罩扩张/羽化。
