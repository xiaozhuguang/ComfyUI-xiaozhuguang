小珠光视频姿势编辑器 · 使用说明

开始编辑

  1. 执行 ComfyUI 节点，打开骨骼编辑器。
  2. 选择人物，通过播放条定位到需要修改的帧。
  3. 完成编辑后点击“保存到节点”，再执行节点得到修改后的姿势。

姿势调节

  • 拖动关节或整体，自动记录关键帧；右侧滑条可调整身体比例。选择“双侧／左侧／右侧”可单独调节手掌、手臂、腿和脚等，左右按人物自身方向区分；头部、脖子和躯干只在双侧模式调节。
  • 新轨道默认全帧生效。右键两个关键帧之间，可设置、追加或取消生效区间。
  • 拖动编号 2 不移动头部；拖动编号 1 会带动脸部点。

姿势补全

  1. 点击“姿势补全”，点击示意图中的关节编号，优先根据前后可靠帧和相邻关节推算补全位置；信息不足时生成短骨骼。待调整位置高亮闪动。已有识别结果也可用补全替代。
  2. 拖动到合适位置，再将播放头移到终点，对同一关节再次补全并调整。两点之间自动形成生效区间；只有一个位置时不会全帧生效。
  3. 已形成区间后，可在区间内继续拖动关节，添加中间关键帧。
  4. 选定编号后，“一键补全此编号”会补全视频中该关节缺失的区间，其他编号不变。
  5. 自动生成的关键帧为红色，拖动调整后变绿色。两种模式均可点击轨道激活，紫色边框表示当前轨道；点击名称旁的锁固定选择，解锁后才可切换轨道；激活后可直接在预览区拖动补全。
  6. 点击“确认补全”返回姿势调节。右键可删除关键帧或整条轨道；“清除全部调整”清除所有编辑。

预览与时间轴

  • 预览区滚轮缩放；Ctrl + 左键或中键拖动平移。上方四角按钮恢复默认视图。
  • 时间条滚轮缩放，右键恢复全帧视图。刻度与关键帧轨道同步对齐。
  • 拖动绿色分界手柄，调整预览区与轨道区的高度。

快捷键

← / →上一帧 / 下一帧
↑ / ↓上一个 / 下一个关键帧；优先跳转激活轨道
Z重置预览位置与缩放
Esc关闭使用说明或右键菜单
